# PROMPT — Premium-сайт нутрициолога «Анна Моложенко»
### Стек: Next.js 14 (App Router) + TypeScript + Tailwind CSS
### Референс структуры и тона: ddwellness.ru (личный бренд эксперта, не конвейер услуг)

Ты — senior frontend-разработчик и арт-директор, который делает премиальные сайты
персональных экспертов в нише здоровья/нутрициологии на Next.js. Твоя задача — собрать
**полноценный проект**, а не один HTML-файл: с компонентами, конфигами и структурой,
которую дальше можно развивать (добавлять страницы, блог, лендинги под рекламу).

Никогда не используй lorem ipsum и общие фразы «мы лучшие». Каждое слово на сайте
пишется под конкретного человека — Анну Моложенко — и её позиционирование
«фармацевт + нутрициолог + эксперт по анализам».

---

## 0. Почему не один HTML-файл

Одностраничный HTML с инлайн-CSS/JS невозможно масштабировать: нельзя переиспользовать
шапку/футер на новых лендингах, сложно менять контент без риска сломать вёрстку, нет
типизации данных (услуги, отзывы, FAQ). Вместо этого:

- Каждая секция — отдельный React-компонент в `/components/sections`.
- Переиспользуемые UI-элементы (кнопки, карточки, бейджи) — в `/components/ui`.
- Контент (услуги, отзывы, стат-числа, FAQ) — вынесен в типизированные объекты в
  `/lib/content.ts`, а не захардкожен в JSX. Это даёт возможность позже подключить
  CMS/Sanity без переписывания вёрстки.
- Картинки — через `next/image` с `next.config` доменом `images.unsplash.com`
  (плейсхолдеры до получения реальных фото Анны).

## STEP 2 — Дизайн-персона (взята с флаера, НЕ дефолтная medical-персона)

Забудь стандартную "medical" палитру (белый + бирюза) — она слишком клинична для
персонального бренда. Флаер Анны задаёт тёплую, женственную, editorial-эстетику —
ближе к wellness-коучу, чем к клинике. Именно такой тон держит и ddwellness.ru.

```
Base:        тёплый кремовый  #F7F1E6
Surface alt: светло-бежевый   #EFE6D8  (альтернирующие секции)
Text dark:   тёмный антрацит  #241F1C
Accent 1 (основной, terracotta): #9C4A3C   — хедлайны-акценты, иконки, кнопки
Accent 2 (глубокий бордовый):    #5C2328   — CTA-баннер скидки, плашки, футер
Accent 3 (тёплое золото):        #B8934A   — подпись/логотип, декоративные акценты, disabled-состояния
```

Шрифты:
- **Display / заголовки:** `Playfair Display` (editorial serif, как в разделе имени на
  флаере) — 600/700 начертание.
- **Акцентная подпись (имя, цитаты):** `Cormorant Garamond` italic — имитирует рукописное
  «Анна» с флаера, использовать точечно (подпись под фото, эпиграфы).
- **Body:** `Nunito` — тёплый, округлый, читабельный на длинных текстах про анализы.

Ощущение: тёплое, доверительное, «эксперт-подруга», а не стерильная клиника.
Никакого neon/glassmorphism-hype — сдержанная editorial-роскошь: много воздуха,
тонкие линии-разделители (как иконки-таймлайн на флаере), крупные фото Анны.

Изображения (Unsplash ID, плейсхолдеры до реальных фото):
```

```

    Hero.tsx
    PainPointsChecklist.tsx     — "Вес не уходит? Выпадают волосы?..." с иконками
    MethodologySteps.tsx        — Анализы → Анамнез → Разбор (3 шага, как на флаере)
    AboutExpert.tsx             — фото + регалии + красный диплом, сертификаты
    ServicesTiers.tsx           — бесплатная консультация / разбор анализов / программа
    LabPartnerBanner.tsx        — блок ЛукаЛаб, чек-ап «Анна Моложенко»
    SymptomQuiz.tsx             — интерактивный квиз-лидмагнит (см. ниже)
    Testimonials.tsx
    DiscountCTA.tsx             — баннер купона -30%
    ContactSection.tsx          — форма + телефон + Telegram QR
    Footer.tsx
  /ui
    Button.tsx, Badge.tsx, SectionLabel.tsx, StatCounter.tsx, Card.tsx
  /widgets
    TelegramFloatingButton.tsx  — плавающая кнопка Telegram (не "звонок")
    ScrollProgressBar.tsx
/lib
  content.ts                    — типизированные данные: услуги, отзывы, шаги, FAQ
  types.ts
/public
  /images                       — сюда позже кладутся реальные фото Анны

```

**Зависимости:** `next`, `typescript`, `tailwindcss`, `framer-motion` (анимации вместо
GSAP/AOS — нативнее для React), `embla-carousel-react` (вместо Swiper), `react-hook-form`
+ `zod` (форма записи с валидацией), `lucide-react` (иконки вместо Font Awesome),
`react-intersection-observer` (счётчики статистики).

## STEP 4 — Компоненты по секциям

### Header
Sticky, прозрачный на верху → бежевый фон + blur при скролле (`useScroll` из
framer-motion). Слева — логотип-подпись «Анна Моложенко» шрифтом Cormorant Garamond
italic. Справа — навигация (Обо мне / Услуги / Отзывы / Контакты), кнопка Telegram и
номер телефона. Мобильное меню — полноэкранный оверлей.

### Hero
Сплит-layout: слева текст, справа портрет Анны (кремовый фон, без тёмного оверлея —
кадр светлый, как на флаере).
- Лейбл: «ФАРМАЦЕВТ · НУТРИЦИОЛОГ · ЭКСПЕРТ ПО АНАЛИЗАМ»
- Заголовок (Playfair, 64–72px): **«Вы устали уставать?»** — прямая цитата с флаера,
  это готовый хук, не придумывай замену.
- Подзаголовок: тезис философии — «Сначала разберёмся, чего действительно не хватает
  вашему организму, — и только потом говорим о добавках».
- Две кнопки: «Записаться на консультацию» (accent 1, заполненная) и «Мой Telegram»
  (outline, иконка Telegram).
- Trust-строка: «Дипломированный фармацевт · Сертифицированный нутрициолог»

### PainPointsChecklist
Прямо под hero. 4 пункта с флаера, каждый — круглая иконка (весы, волосы, батарея,
луна) в терракотовой обводке + вопрос:
`Вес не уходит? / Выпадают волосы? / Нет энергии? / Плохой сон?`
Анимация: framer-motion stagger при появлении в viewport, `once: true`.

### MethodologySteps
Горизонтальный таймлайн из 3 шагов (иконка → подпись), как связка иконок на флаере:
**Анализы → Анамнез → Индивидуальный разбор.** Подчеркни фразой над блоком:
«Не спешите покупать БАДы» (accent 2, крупно) / «Не спешите» обычным текстом.

### AboutExpert
Тёмно-бордовая секция (accent 2 фон, белый текст — это единственная тёмная секция
верхней половины сайта, для контраста). Слева фото, справа:
- Регалии списком с иконкой чек-марк: «Дипломированный фармацевт (красный диплом)»,
  «Сертифицированный нутрициолог», «Индивидуальный разбор анализов», «Персональный
  подход к каждому».
- Короткая личная цитата Анны курсивом (Cormorant Garamond) — по аналогии с блоком
  «Рада приветствовать вас!» на ddwellness.ru.

### ServicesTiers
Три карточки-тарифа (паттерн ddwellness: бесплатная консультация → платная →
программа), а не плоский грид «услуг» из старого промпта:
1. **Первичная консультация** — бесплатно / 20 минут, знакомство и определение цели.
2. **Разбор анализов** — цена по запросу, индивидуальная расшифровка + рекомендации.
3. **Персональная программа** — цена по запросу, комплексное сопровождение
   (недели/месяцы), самая заметная карточка (accent-обводка, «популярный выбор»).
Карточки на светлом фоне, мягкая тень при hover (никакого glassmorphism — это не
трейд-ниша, стекломорфизм тут будет выглядеть неуместно холодно).

### LabPartnerBanner
Блок-партнёрка под сеть **ЛукаЛаб**, взят прямо с флаера: логотип-плейсхолдер +
текст «Чек-ап «Анна Моложенко» доступен во всех лабораториях ЛукаЛаб. Сдайте анализы
и приходите на профессиональную расшифровку.» Светлый фон, тонкая рамка, не кричащий —
это партнёрское упоминание, а не реклама.

### SymptomQuiz — интерактивный лид-магнит (заимствовано с ddwellness.ru)
Это ключевое отличие от старого шаблона: вместо статичной формы — мини-квиз с
чекбоксами по симптомам (по образцу теста ЖКТ на ddwellness), под нишу Анны — симптомы
дефицитов (усталость, выпадение волос, набор веса, бессонница и т.д., 8–10 пунктов).
- Состояние на `useState`, прогресс-бар сверху квиза.
- В конце — простая интерпретация по количеству отмеченных симптомов (низкая/средняя/
  высокая вероятность дефицита) + форма «оставьте e-mail — пришлём разбор».
- Это компонент, который реально двигает конверсию: понижает порог входа сильнее, чем
  прямая заявка на консультацию.

### Testimonials
Карусель на `embla-carousel-react`, 3 отзыва видно на десктопе, автоплей с паузой на
hover. Каждая карточка: рейтинг звёздами (accent 1), цитата, имя, приписка
«через Telegram» или «клиент программы» (НЕ «Google Reviews» — у эксперта аудитория
в Telegram, это должно быть отражено честно).

### DiscountCTA
Баннер купона прямо с флаера: **«-30% на консультацию по здоровью»**, бордовый фон
(accent 2), крупная цифра скидки, подпись «Предъявите купон при записи на
консультацию». Кнопка — запись в Telegram или по телефону.

### ContactSection
Двухколоночный блок: слева — телефон (click-to-call), Telegram-ссылка, QR-код
(изображение, как на флаере, подпись «Сканируй и подписывайся»); справа — форма
записи на `react-hook-form` + `zod` (Имя / Телефон / Что беспокоит — select / Сообщение
опционально), сабмит без бэкенда — просто success-состояние на клиенте.

### TelegramFloatingButton (виджет, НЕ click-to-call)
Фиксированная круглая кнопка снизу справа — иконка Telegram, ведёт на канал Анны.
Это принципиальное отличие от старого промпта: у эксперта в нутрициологии
основной канал коммуникации — мессенджер/канал с контентом, а не звонок.
Пульс-анимация раз в несколько секунд, тултип «Мой Telegram» при hover на десктопе.

### Footer
Тёмный (accent 2 или near-black), тонкая золотая (accent 3) верхняя линия. 3 колонки:
Бренд (подпись + соцсети), Навигация, Контакты (телефон, Telegram, «Уточнить у
клиента» для email/адреса). Копирайт снизу.

## STEP 5 — Анимация (React-нативный стек, не CDN-скрипты)

1. Хиро: `framer-motion` — заголовок и подзаголовок появляются с `staggerChildren`,
   единственная анимация, которая стартует сразу при загрузке.
2. Остальные секции: `whileInView` + `viewport={{ once: true, margin: '-80px' }}`,
   стандартный вход — `fade + y: 24`.
3. Чек-лист болей и регалии — стагтер по 80–100ms между элементами.
4. Счётчики (если будут stat-числа) — `react-intersection-observer` + локальный
   `requestAnimationFrame`-тикер с easing "ease-out", без linear-счёта.
5. Квиз — переходы между шагами через `AnimatePresence`.
6. Карусель отзывов — встроенный автоплей embla, без доп. анимации поверх.
7. Правило сдержанности: не анимируй больше 60% элементов в секции — часть контента
   должна просто появляться, это выглядит дороже, чем тотальная анимация всего.

```

Заголовки секций:      40–44px desktop / 28px mobile, Playfair Display 600
